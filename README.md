# Anime-Random-Image-Generator

**Anime Image Generator** made with HTML & JavaScript
> ⚠️ Warning: Everything is mashed into **one long function** (`fetchData()`), so it’s a bit messy 

## Features ✨

- Fetches a random anime image from `waifu.im` API.
- Shows the image, signature, and source.
- Automatically removes the old one before showing a new image.

## How to Play~ 🖱️

1. Open `index.html` in your browser~  
2. Click the **Process** button~ 
3. Watch the magic happen!
   - Image appears  
   - Signature appears  
   - Source appears
